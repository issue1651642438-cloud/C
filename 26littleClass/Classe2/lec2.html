天平倾斜：如何理解等于号

prev = curr;
curr = nextTemp;
  • prev = curr;
  • 人脑直观理解：把 curr 的值给 prev
  • 计算机层面：prev 的内存地址保存 curr 指向的节点地址
  • 关键点：这是指针赋值，不复制节点内容，只复制地址
  • curr = nextTemp;
  • 不是“curr 变成了下一个节点”，而是指针移动

流式执行：阻塞式赋值的陷阱

可以更改这几行的顺序吗？

Node* nextTemp = curr->next;
curr->next = prev;
prev = curr;
curr = nextTemp;

流式执行：阻塞式赋值的陷阱

Node* nextTemp = curr->next;
curr->next = prev;
prev = curr;
curr = nextTemp;
  • 1. 必须先保存下一节点指针 → nextTemp = curr->next，否则信息丢失
  • 2. 指针反转 curr->next = prev → 顺序敏感
  • 3. prev = curr; 移动前驱指针，依赖 curr 的当前值
  • 4. curr = nextTemp; 移动当前指针，必须在前面步骤之后执行
  • ⚠️ 如果改变顺序 → 链表破坏、指针指向错误

流式执行：阻塞式赋值的陷阱

阻塞式赋值

  • 代码必须按照特定顺序执行，每一步都依赖前一步的结果
  • 执行顺序按照照代码书写的顺序进行，不能随意调整
  • 如果中途有函数调用关系，则优先执行函数内部的代码，完成后再继续当前函数的下一行
  • 在进入循环/递归时，必须保证每次迭代/调用的状态正确，不能因为顺序错误导致状态混乱

拓展：非阻塞式赋值

// Verilog 非阻塞赋值示例
always @(posedge clk) begin
    prev <= curr;
    curr <= nextTemp;
end
  • 1. 非阻塞赋值 (<=)：所有右值同时读取，左值同时更新
  • 2. 顺序不会阻塞，可以并行理解多个赋值
  • 3. 与阻塞赋值 (=) 对比：阻塞赋值必须严格顺序执行
  • 4. 可以理解为“先看右边值，再同时更新所有左边”

循环新生：迭代赋值分析

正确循环的条件

  • a. 初始化变量状态正确
  • b. 每次迭代右值使用前已经保存
  • c. 左值更新后能满足下一次迭代的需要
  • d. 循环终止条件清晰且可达

循环新生：迭代赋值分析

泛化理解循环设计：只要连续两次迭代之间变量衔接正确，整个循环就正确。

  • 1. 循环本质 → 重复执行一组动作，每次迭代处理局部最小动作
  • 2. 变量衔接原则 → 检查每次迭代结束时变量状态能否满足下一次迭代的初始要求
  • 3. 抽象方法 → 可以连续观察两次迭代，验证左值更新、右值读取、依赖顺序是否正确

多项式运算与输出：有序链表的维护

Poly add(const Poly &A, const Poly &B) {
    Poly head = new Node{0, 0, nullptr};
    Node* tail = head;
    Node* p = A->next;
    Node* q = B->next;
    while (p && q) {
        if (p->exp > q->exp) {
            tail->next = new Node{p->exp, p->coef, nullptr};
            p = p->next;
        } else if (p->exp < q->exp) {
            tail->next = new Node{q->exp, q->coef, nullptr};
            q = q->next;
        } else { // 指数相同
            int sum = p->coef + q->coef;
            if (sum != 0) tail->next = new Node{p->exp, sum, nullptr};
            p = p->next;
            q = q->next;
        }
        if (tail->next) tail = tail->next;
    }
    while (p) { tail->next = new Node{p->exp, p->coef, nullptr}; tail = tail->next; p = p->next; }
    while (q) { tail->next = new Node{q->exp, q->coef, nullptr}; tail = tail->next; q = q->next; }
    return head;
}

多项式运算与输出：有序链表的维护

Poly mul(const Poly &A, const Poly &B) {
    Poly result = new Node{0, 0, nullptr};
    for (Node* p = A->next; p; p = p->next) {
        for (Node* q = B->next; q; q = q->next) {
            int e = p->exp + q->exp;
            int c = p->coef * q->coef;
            // 插入到result中（按指数降序）
            Node* prev = result;
            Node* cur = result->next;
            while (cur && cur->exp > e) { prev = cur; cur = cur->next; }
            if (cur && cur->exp == e) { // 已存在指数
                cur->coef += c;
                if (cur->coef == 0) { // 系数为0就删除节点
                    prev->next = cur->next;
                    delete cur;
                }
            } else { // 插入新节点
                Node* newNode = new Node{e, c, cur};
                prev->next = newNode;
            }
        }
    }
    return result;
}

模式匹配：KMP

vector buildNext(const string &P) {
    int m = P.size();
    vector next(m, 0);
    int j = 0; // 当前匹配长度

    for (int i = 1; i < m; ++i) {
        while (j > 0 && P[i] != P[j]) {
            j = next[j-1]; // 回退状态
        }
        if (P[i] == P[j]) j++;
        next[i] = j; // 更新状态
    }
    return next;
}

模式匹配：KMP

vector KMP(const string &T, const string &P) {
    vector res;
    vector next = buildNext(P);
    int n = T.size(), m = P.size();
    int j = 0; // 当前匹配长度

    for (int i = 0; i < n; ++i) {
        while (j > 0 && T[i] != P[j]) j = next[j-1];
        if (T[i] == P[j]) j++;
        if (j == m) {
            res.push_back(i - m + 1); // 匹配成功
            j = next[j-1]; // 状态衔接，继续寻找下一个
        }
    }
    return res;
}
